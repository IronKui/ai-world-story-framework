# 动态世界观文字游戏框架

导入一份世界观文档，AI 依据它实时生成剧情、道具、事件与 NPC 的桌面文字游戏。

框架本身**不含任何预设剧情、道具表或事件脚本** —— 你导进去什么世界，它就在什么世界里演。

---

## 开始之前：你需要一个 DeepSeek API Key

这一条必须先说清楚，因为它决定你能不能玩起来。

程序本身**不含 AI 能力**，它调用的是你自己的 DeepSeek API Key。你需要：

1. 到 <https://platform.deepseek.com> 注册账号
2. 充值（生成一份世界观约 ¥0.01，玩一回合约 ¥0.005，很便宜但**不是免费**）
3. 在控制台创建一个 API Key
4. 把它填进程序的「设置 → API 设置」

Key 只保存在你自己电脑上，不会上传到任何服务器。

**没有 Key 也能打开程序**，但只能浏览界面，不能开始游戏。

## 安装

### 用安装包（推荐）

下载 `AIWorldStoryFramework-Setup-0.1.0.exe`，双击安装，从开始菜单启动。

> 安装包没有购买代码签名证书，Windows 可能会弹出「已保护你的电脑」的蓝色提示。
> 点「更多信息」→「仍要运行」即可。这是未签名程序的常见提示，不代表程序有问题。

### 从源码运行

```bash
git clone https://github.com/IronKui/ai-world-story-framework.git
cd ai-world-story-framework

python -m venv .venv
.venv/Scripts/python.exe -m pip install -r requirements.txt
.venv/Scripts/python.exe main.py
```

需要 Python 3.10 以上（PyQt6 的 wheel 是 `cp310-abi3`，兼容 3.10+）。

> 用国内镜像装 PyQt6 可能失败，因为镜像站没有分发这个包。
> 如果报「Could not find a version that satisfies the requirement PyQt6」，
> 加上官方源：`-i https://pypi.org/simple`

## 怎么玩

### 第一次打开

1. **设置 → API 设置**，填入 API Key，点「测试连接」确认能通
   （这一步不消耗 token）
2. **游戏 → 世界观文档**
   - 点「导入示例」可以立刻拿到一份附带的设定，马上开玩
   - 或者点「用 AI 生成…」，用一句大白话描述你想玩的世界，
     程序会写出一份完整设定（约 ¥0.01）
   - 也可以点「导入文档…」用你自己的 `.md` / `.txt` 设定
3. **游戏 → 开始新游戏**

### 玩的时候

- 左侧上方是剧情，下方是操作区
- 操作区有两种方式：**点选项**，或者**在输入框里自己打字**
- 右键面板可以查看道具详情，支持使用与丢弃
- 右侧显示世界状态、玩家状态、势力关系与毁灭进度

### 一些值得知道的设计

**世界会记住你的选择。** 位置、时间、势力关系、身上的伤、世界的印记
都会持续累积，并影响后续所有生成。

**世界毁灭不会随机发生。** 毁灭需要你在连续多个回合里反复做出
逼近禁忌的重大选择才会逐步逼近。程序里有一个「毁灭进度」，
进度不够时，任何世界毁灭的描写都会被校验拦下并重写。

**AI 生成的内容会过校验。** 每一次生成之后，程序会拿世界观原文
再问一次模型「这段内容和设定冲突吗」，冲突就带着原因重写，最多 3 次。
3 次都不过会弹窗提示你换个操作。

**存档只保留摘要。** 不会保存完整对话历史，而是每 6 个回合把近期经历
折叠进一段长期摘要。所以玩一百小时和玩十分钟，送给 AI 的上下文是同一个量级。

## 花费

程序会在**状态栏右下角**实时显示本次运行的花费，**设置 → 用量与花费** 里有详细统计。

按 DeepSeek 官方价目估算（2026-09 抓取）：

| | 约合 |
|---|---|
| 生成一份世界观（约 3000 字） | ¥0.01 |
| 一个游戏回合 | ¥0.005 |

**这是估算值，不是账单。** 实际以 DeepSeek 平台为准。
程序无法自动识别中国法定节假日，那些日子会按高峰价估算（估高不估低）。

一个省钱的建议：**思考模式默认关闭**。实测同一句提示词，开启时输出 17 token、
关闭后只需 1 token，而生成质量没有肉眼可见差别。你可以在
「设置 → API 设置」里开启它。

## 常见问题

**Q：窗口里的中文看不懂 / 显示成方块？**
系统缺少中文字体。Windows 一般不会有这个问题；Linux 需要装
`fonts-noto-cjk` 之类的字体包。

**Q：生成出来的内容和我的设定对不上？**
先确认世界里没写死剧情。世界观文档应该描述**世界的规则**，
而不是主角和剧情走向 —— 剧情是程序实时生成的，写死了会互相冲突。
另外，设定里写清楚「代价」「禁忌」这类硬规则，校验才有的放矢。

**Q：游戏数据在哪？**
**工具 → 打开数据目录**。安装版在 `%LOCALAPPDATA%\AIWorldStoryFramework`，
里面是配置、存档、世界观副本和日志。备份存档直接复制这个目录。

**Q：报错说连续 3 次无法生成符合世界观的内容？**
通常是世界观文档内部自相矛盾，或者你的操作方向与设定冲突得太厉害。
可以打开「工具 → 调试日志」看具体冲突点。

**Q：怎么自定义界面颜色？**
**设置 → 外观设置**，有 5 套配色，也可以选一张自己的图片当背景。
改动需要重启程序后生效。

## 开发

```
core/     业务逻辑，不依赖界面
  api_client.py   DeepSeek 接口封装（流式、错误分类）
  validator.py    世界观一致性校验 + 重试循环
  doom.py         毁灭进度与硬约束
  worldgen.py     世界观生成 agent
  events.py       动态事件生成
  items.py        动态道具生成
  game.py         回合主循环编排
ui/       界面层
  themes.py       5 套配色方案
  main_window.py  主窗口与主循环
tests/test_core.py  回归测试
```

跑测试（不依赖 pytest，也不需要 API Key）：

```bash
.venv/Scripts/python.exe tests/test_core.py
```

测试全部在临时目录里操作，不会碰你的真实配置和存档。

### 改代码时注意

- **`ui/styles.py` 的 `COLORS` 必须原地修改**。全项目有 80 多处直接读它，
  重新赋值会让已持有引用的地方拿到旧颜色。
- **`core/worldgen.py` 的提示词锁死了 `core/world.py` 的解析约束**
  （Markdown 标题分节、字数区间）。改解析器时要同步改提示词。
- **不要移除 `main.py` 里的 `install_excepthook()`**。实测：不装的话，
  PyQt6 在槽函数抛未捕获异常时会直接 abort 进程，用户看到的是窗口凭空消失。
